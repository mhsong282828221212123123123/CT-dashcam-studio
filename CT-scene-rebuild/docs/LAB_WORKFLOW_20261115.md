# 실험실 사용 연결 정리 · 2026-11-15

기존 편집기 실험실 / Lab → 주행 재현 v2 / 분석·검토·MP4는 독립 엔진의 현재 src를 실행한다. 메뉴의 전방 원본 전달과 격리 프로세스 실행을 adapter 검사로 확인했다.

## 변경

- 최근 완료 결과 목록과 선택 결과 열기/새로고침을 추가했다. 완료 manifest와 전체 영상 보고서가 있는 결과만 나열하며 preview는 제외한다. 실제 열기에서는 기존 artifact 무결성 검사를 유지한다.
- MP4 내보내기에서 분석 결과 폴더 내부 저장을 차단한다. 영상 외에도 report 등 결과 파일을 덮어쓰지 않게 했다.
- 분석 완료 시 최근 결과 목록을 갱신한다.

## 검증

- 실제 Qt offscreen 이벤트 루프에서 현재 시내 59.4초 결과를 목록으로 열었다. 31초로 이동 후 39개 유효 프레임을 받아 32.8초까지 재생했다.
- 내보낸 MP4와 결과 영상 SHA256 동일. report.json으로 저장을 시도해 차단되고 원본 내용이 유지되는지 확인했다.
- 분석 취소 후 프로세스 종료 및 버튼 복구 확인.
- 단위 검사 346 PASS, 기존 편집기 adapter PASS.
- 화면 캡처를 확인했다. 직접 데스크톱 마우스 조작 검수는 아니며 새 원본 전체 추론은 이번 단계에서 다시 실행하지 않았다. 기존 추론 결과를 재사용했다.
- 첫 smoke는 미디어가 열리기 전 seek를 호출해 assertion 실패. 실패 출력은 보존하고 미디어 로드 후 seek하도록 검사 코드를 수정한 두 번째 실행이 통과했다.

검사 기록: runs/current-review-ui-smoke-002/review.json 및 window.png. 검사 도구: tools/smoke_current_review_app.py. 재현 알고리즘/기존 영상/Drive 파일은 이번 단계에서 변경하지 않았다.

사용: 편집기의 실험실 메뉴에서 v2를 열고 최근 완료 결과에서 practical-display-oct22-full-001 또는 practical-display-oct02-full-001을 선택한 뒤 선택 결과 열기를 누른다. 별도 영상 저장은 MP4 내보내기를 사용한다.
