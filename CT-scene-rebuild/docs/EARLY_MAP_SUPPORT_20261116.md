# 짧은 교차로 진입 구간의 지도 표시 보완 · 2026-11-16

## 원인과 변경

Oct22 초반 0~6.6425초에는 도로 법선 정렬 anchor 9개가 있었으나 자차 이동 범위가 9.67m여서 일괄 15m 기준에서 탈락했다. 목표 횡방향 보정값의 변동은 약 0.51m이고 도로 방향도 안정적이었다. 데이터가 전혀 없었던 것이 아니라 좌우 정렬에도 긴 이동 범위를 요구했던 문제다.

짧은 지역 보정에서만 다음 제한을 적용했다: 6개 이상 anchor, 3초 이상 시간, 3m 이상 이동, 도로 법선 변화 3도 이내, 보정값 범위 1m 이내, 보정 후 법선 잔차 p90 0.5m 이내. 방향이 변하거나 값이 흔들리는 짧은 구간, 정차한 입력은 기존처럼 보류한다. 도로 종방향의 불확실성은 남기며 앞뒤 위치나 scale을 새로 추정하지 않는다. 기존 전체 정렬의 15m 조건은 유지한다.

## 실행과 검증

- Oct22 초반 9개 anchor가 추가됐고 초반 법선 잔차 p90은 약 0.252m였다. 이 수치는 지도와 영상 도로의 표시 정렬 잔차이며 실제 도로/차량의 미터 정확도가 아니다.
- 회전 뒤 33.309~44.987초의 기존 13개 anchor 지역은 유지했다. 지역 주변 지도 면 수는 30→63으로 늘었으며 전체 도로 연결 복원을 의미하지 않는다.
- 0/6/12/40초의 전후 화면을 확인했다. 하단 4채널을 포함한 전체 59.4초, 1188프레임과 마지막 5초를 검사했다.
- actor와 render-state 파일은 기존 결과와 바이트 동일하다. 차량·자차·차선 운동을 바꾸지 않았다.
- Aug25의 기존 지도 context를 새 코드로 다시 계산해 전체 결과 dict가 정확히 같음을 확인했다. 해당 영상은 불필요하게 다시 합성하지 않았다.
- 코드 검사 362 PASS. 짧지만 안정적인 진입은 좌우만 보정하고 정차·jitter·회전 중인 짧은 자료는 거부하는 paired 검사를 추가했다.
- 기존 차량 겹침 14쌍·프레임의 strict FAIL은 그대로다. 이번 수정으로 차량 추적/충돌 문제가 해결됐다고 주장하지 않는다.
