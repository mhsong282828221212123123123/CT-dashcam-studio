# 원본 직접 정답 확장과 두 번째 학습 · 2026-11-25

사용자 요청에 따라 제가 원본을 보고 접점·차체 앞뒤를 직접 표시해 학습 자료를 늘렸다. 이전 결과를 정답으로 복제하지 않았다. 이번에도 실제로 새 가중치를 학습했으나 새 날짜에서 접점 추정이 나빠져 기본 3D에는 적용하지 않았다.

## 직접 표시한 자료

원본10클립106개 차량 크롭이다. 기존61개에 Aug26·Aug28·Oct22·Oct26의45개를 추가했다. 새 자료는 접점 두 곳을 각각 표시하고 그 중간값을 이미지 앵커로 삼았다. 가드레일·다른 차량·수풀에 가린 바퀴는 찍어서 맞추지 않고 null로 제외했다. 방향이 불명확한 부분 차량도 null이다.

학습 전 표시점을 원본 크롭에 겹쳐 다시 검사했다. Aug26-008 트럭의 접점은 수풀과 볼라드로 가려진 것으로 재판정해 제외했다. 이 재검토는 모델 예측이나 최종 평가 결과를 보기 전에 했다. 초기 라벨은 runs/contact-learning-labels-v2-new-001/manifest-before-second-review.json에 보존했다. 최종 정답은 configs/contact-learning-annotations-v2.json이며, 최종 표시 사진은 같은 runs 폴더의 *-labelled-final.jpg이다.

총106개 중 접점 정답62개, 방향 정답102개다. 새45개 중 유효한 바퀴 접점 쌍26개다. 제가 이미지에서 직접 표시한 잠정 정답이며 실측 3D 좌표나 독립적인 인간 검수 자료는 아니다. 가시 바퀴의 이미지 접점 중간과 차량의 실제3D 중심은 다르다.

## 분리와 재학습

- 학습63개: 기존 Oct02·Oct18에 Aug26·Aug28·Oct22를 추가. 접점37개, 방향61개.
- 조정32개: Aug20와 이전 Nov01 평가 영상. 접점19개, 방향31개. 이전 평가 영상을 개발에 썼으므로 이번에는 최종 평가로 부르지 않는다.
- 새로운 최종 평가11개: Oct26. 학습·선택에 넣지 않았다. 접점6개, 방향10개.

같은 날짜/세션과 동일 원본 이미지가 분할 사이를 넘으면 오류로 중단한다. 접점 쌍의 좌표가 잘못됐거나 중간값과 학습 표적이 다르거나 가린 접점이 남아 있어도 오류로 중단하도록 검사했다.

기존 MobileNetV3 특징 추출부를 고정하고 접점·방향 출력 가중치를 CPU로 다시 학습했다. 접점과 방향 모두 이미지 특징 강도0.25가 선택됐다. v1의 접점 선택은 이미지 특징0이었던 것과 다르다. 전체 신경망을 미세 조정한 것은 아니며 CUDA도 사용하지 않았다.
