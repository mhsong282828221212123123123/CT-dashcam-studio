# 실용 수준 종료 기준 · 2026-11-15

사용자 최신 지시: 상용 계측 수준을 목표로 삼지 않는다. 원본을 봤을 때 납득 가능한 주변 차량 재현이면 다음 단계로 넘어간다.

- B필러 영상이 없어 생기는 사각지대 소실과 작은 위치 오차는 허용한다. 해당 누락을 의무 복구 대상으로 삼지 않는다.
- 가까운 차량의 뚜렷한 순간 이동, 반대 방향 표시, 심한 중첩을 우선한다.
- 원거리 차량의 미세 ID/위치 문제와 한 프레임의 작은 관통 때문에 작업을 반복하지 않는다.
- 추정 고스트가 가까운 실제 관측 차량과 깊게 겹치면 관측 차량을 우선해 해당 고스트 표시를 생략한다. 원본 관측/전역 ID/actor 기록은 보존한다.
- 기존 정밀 수치 FAIL을 PASS로 바꾸지 않는다. 수치 진단과 이번 실용 범위의 종료 판단을 구분한다.
- 하나의 구간에 맞추는 반복 보정보다 다른 주행 장면에서 큰 회귀가 없는지 확인한다.

이번 구현은 collision_constraints.omit_conflicting_predictions로, 자차 30m 이내의 비관측 고스트가 관측 차체 또는 자차와 0.5m 초과 SAT 관통을 만들 때만 표시를 생략한다. 실제로 보이는 두 차량은 숨기지 않고, 차로/위치/방향을 억지로 바꾸지 않는다. 필러 추론 개선 및 먼 트럭 ID 실험은 보류한다.
