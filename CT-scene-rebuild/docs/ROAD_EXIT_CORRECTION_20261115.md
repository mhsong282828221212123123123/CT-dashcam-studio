# 영상 말미 우측 차량의 도로 이탈 수정 · 2026-11-15

사용자가 지적한 현재 고속 영상의 말미를 확인했다. 전방 `front-0003`에서 우측 `right_repeater-0003`으로 연결된 검은 승용차가 실제로는 3차로를 유지하지만, 3D에서는 54~58초에 도로 오른쪽으로 벗어났다. 원본 증거: `runs/oct02-right-tail-source-001.jpg`. 수정 전 검토: `runs/oct02-tail-road-review-001.jpg`.

## 원인과 수정

같은 차량이라는 ID 연결은 유지됐지만 우측 카메라의 겉보기 높이 기반 좌표가 거리 증가에 따라 우측으로 치우쳤다. 범위 미정으로 남겨 둔 측면 좌표가 전방 ID에 합쳐진 뒤에도 그대로 사용됐다. 도로 종료나 자차 좌표 이탈이 원인이 아니다.

`side_paint_geometry.py`에 서로 다른 거리에서 관측되는 동일 도색을 이용한 조건부 보정을 추가했다. 두 도색으로 scale을 맞출 수 없을 때는 scale을 고정하고, 카메라로부터의 종방향 거리에 비례하는 좌우 편향과 offset만 추정한다. 최소 한 차로 폭의 거리 변화, 반복 프레임, 뒤 시간 구간의 오차 검사, 각도에 대응하는 계수 상한을 요구한다. 차량 좌표는 이 계수를 맞추는 근거로 쓰지 않는다.

이번 우측 계수는 range shear -0.16907, offset +0.61106m다. 뒤 시간 구간의 도색 오차는 중앙값 0.057m / p90 0.161m이며 정렬 전 중앙값은 1.495m다. 이것은 기존 전방 도로에 대한 측면 도색 정렬 오차이고, 차량 위치 실측 오차나 공장 렌즈 보정값은 아니다. 학습 거리 밖의 작은 각도 보정 적용도 포함하므로 특정 촬영 조건에서의 추정으로 취급한다.

명확한 측면 지면 관측으로 기존 3차로를 판단하고, 잘린 앞부분과 작은 박스의 후반 접촉점은 같은 추적 ID의 안정된 운동으로 최대 4초까지만 보완한다. 마지막 직접 추적 이후 0.2588초는 확인된 카메라 연결과 운동을 사용해 짧게 예측한다. 이 보완은 직접 관측이라고 표시하지 않으며 관측이 없으면 기존 고스트 정책을 따른다. 예측은 최대 0.8초이고 도로 지지가 없거나 차로/운동이 불명확하면 거부한다.

도로 폭을 늘리거나 자차 궤적을 변경하지 않았다. 해당 차량의 차체 모서리가 도로 안에 유지되는지 별도 검사했다.
