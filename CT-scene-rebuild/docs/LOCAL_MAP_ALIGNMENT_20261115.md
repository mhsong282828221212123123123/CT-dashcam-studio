# 구간별 지도 표시 정렬 · 2026-11-15

## 이번 진행

이전 Oct22는 전체 지도에 하나의 횡방향 보정을 적용하면 anchor 일관성이 59%여서 주변 지도를 모두 보류했다. 이번에는 전체 정렬이 실패한 경우 도로 ID별로 독립적인 영상 도로 근거를 검사한다. 유효한 지역만 공유 공간 보정으로 연결하며 차량·자차·차선은 수정하지 않는다.

## 구현

- 본선 전체에 하나의 지도 보정을 강제하지 않는다. 6개 이상 anchor와 15m 이상 영상 도로 범위가 있는 지역에서만 제한된 도로 법선 보정을 사용한다.
- 국소 정렬 지역 사이의 지도 정점은 같은 공간 보정장을 사용한다. 서로 연결된 도로가 공유한 node를 서로 다른 방향으로 끌어 접합부를 분리하지 않는다.
- 주변 도로는 짧은 구간으로 나눠 확인 가능한 지역 35m 밖을 생략한다. 이 거리는 표시 지원 범위이며 실측 정확도 보증이 아니다.
- 본선은 계속 camera corridor와 통합한다. 지도 lane/width 태그로 차로를 만들지 않고 GPS 위치에 자차를 끌어당기지 않는다.

## 결과와 한계

- Oct22: 33.309~44.987초에서 얻은 13개 anchor가 지원하는 도로 지역을 복구했다. 지역 법선 잔차 p90은 약 1.22m이나 지도-영상 표시 정렬 잔차이며 차량 거리 정확도가 아니다. 영상 25/34/40/45초의 전후 화면을 확인했다.
- 초반의 지원되지 않은 지도 지역은 여전히 보류한다. 교차로 전체와 모든 합류 연결이 완성됐다고 주장하지 않는다.
- Aug25: 기존 전역 정렬과 본선 통합을 유지했다. 최종 MP4가 이전 업로드와 SHA256까지 동일하므로 중복 업로드하지 않았다.
- 두 전체 영상 2369프레임, 각 마지막 5초를 검사했다. actor 파일과 render-state 파일은 원본 결과와 바이트 동일하며 camera road도 같다.
- strict 수치 겹침 FAIL은 유지한다: Oct22 14쌍·프레임, Aug25 8쌍·프레임. 이번 도로 표시 개선으로 차량 운동이 개선됐다고 주장하지 않는다.
- 코드 검사 360 PASS. 구간마다 지도 편향이 다를 때의 지역 보정, 공유 node 접합 유지, 이전 본선/평행도로 구분 음성 검사를 포함한다.
