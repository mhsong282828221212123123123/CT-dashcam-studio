# v5 자차 기준 3D 지면 미터 오차 직접 학습 결과 · 2026-11-25

## 1. 목적과 구조 변경 (방향 제외, 자차 기준 3D 지면 위치 집중)

v4에서 2D 접점 오차는 개선됐지만, 원거리 차량의 수직 픽셀(`v`) 오차가 `depth = height / ray_y` 투영 시 5~10m로 폭증해 3D 지면 오차가 `0.96m → 1.54m`로 악화했다.
이에 v5에서는 **방향(각도) 헤드를 완전히 제외**하고, 자차 기준 3D 지면 투영 오차(미터) 자체를 최소화하는 구조로 개편했다.

- **데이터셋 (`configs/contact-learning-annotations-v5.json`, 20개 세션 · 총 242개)**:
  - **학습 (`train`, 178개 · 14개 세션)**: 유효 접점 **97개**(`front` 34, `left_repeater` 40, `right_repeater` 23).
  - **조정 (`validation`, 35개 · `aug25·sep17·sep20`)**: 유효 접점 **22개**(야간 포함).
  - **새 최종 평가 (`test`, 29개 · 미사용 3개 세션 `aug22·aug30·pilotext`)**: 유효 접점 **12개**(`front` 5, `left_repeater` 4, `right_repeater` 3 — 전 카메라 3개 이상). 최종 평가 확인 후 재조정 없음.
- **모델 구조 (`tools/train_contact_v5.py`)**:
  - **수평 `u`**: 14×14 FPN Spatial Soft-Argmax로 크롭 내부 바퀴 접점 수평 위치 추정(이동 등변성 + 좌우 반전 TTA).
  - **수직 `v`**: YOLO 상자 바닥점 근처로 제한된 잔차 헤드 `v_box = 0.97 + 0.04 * tanh(Δv)` (`[0.93, 1.01]`)로 원거리 깊이 폭주를 구조적으로 차단.
  - **손실 함수**: 현재 프로토타입 카메라 투영(`surrounding.project_contact`)의 국소 야코비안(미터/픽셀 비율)을 이용해 **자차 기준 3D 지면 미터 거리 오차**를 직접 최소화.

## 2. 성적 (자차 기준 3D 지면 투영 오차, 프로토타입 캘리브레이션 기준)

*(주의: 실측 LiDAR/GPS 정답이 아니라, 직접 표시한 바퀴 접점의 지면 투영 좌표 대비 오차이며 차량 3D 중심 오차와는 다르다.)*

| 분할 | 접점 수 | 기존 상자 바닥점 (평균 / 중앙값 / p90) | v5 모델 (평균 / 중앙값 / p90) |
|---|---:|---|---|
| 학습 (`train`, 14개 세션) | 97 | 1.42 m / 0.67 m / 2.51 m | 0.75 m / 0.31 m / 1.04 m |
| 조정 (`aug25·sep17·sep20`, 야간 포함) | 22 | 0.96 m / 0.82 m / 1.72 m | **0.79 m / 0.52 m / 1.53 m** (-18.0% / -36.4% / -10.9%) |
| **새 최종 평가 (`aug22·aug30·pilotext`)** | **12** | **2.08 m / 0.70 m / 2.03 m** | **1.91 m / 0.53 m / 2.92 m** (평균 -8.3%, 중앙값 -23.4%) |

### 판정: 기본 3D 미적용 유지 (`runtime_adopted=false`)

- v4에서 `0.96m → 1.54m`로 악화했던 `aug25·sep17·sep20`에서 v5는 **평균 `0.79m`(-18.0%) · 중앙값 `0.52m`(-36.4%) · p90 `1.53m`(-10.9%)**로 전 지표가 크게 개선됐다.
- 완전 미사용 `aug22·aug30·pilotext`에서도 **3D 평균 오차 `2.08m → 1.91m`(-8.3%), 중앙값 `0.70m → 0.53m`(-23.4%)**로 개선됐으나, 원거리 1개 표본의 영향으로 p90(`2.03m → 2.92m`)이 기준선을 넘어 엄격 후보 기준(`projected_3d_ground_m_candidate_pass`)은 `false`다.
- 또한 프로토타입 카메라 설치 각도·높이 검증 및 다중 프레임 연속성 검증 전이므로 `models/contact-adapter-v5`는 실험 가중치로 보존하고 기본 3D에는 미적용(`applied=false`, `metric_position_available=false`) 상태를 유지한다.
