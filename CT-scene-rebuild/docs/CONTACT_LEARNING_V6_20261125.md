## 2. 모델 구조 및 개선점 (`models/contact-adapter-v6`)

- 방향(각도) 헤드 없이 **자차 기준 3D 지면 위치**에만 집중(`14×14 FPN` 수평 `u` Spatial Soft-Argmax + 제한 `v` 잔차 `0.97±0.04` + 좌우 반전 TTA).

- CPU 전용 학습(42초), 단일 ONNX 패키지(`contact-encoder.onnx`), CUDA 미사용.
