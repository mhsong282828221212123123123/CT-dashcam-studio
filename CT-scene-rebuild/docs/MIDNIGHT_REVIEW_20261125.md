### 편집기 연결과 실패 표시

편집기는 `.venv`가 있는 예전 소스를 먼저 골라 새 Git 소스를 건너뛰고 있었다. 현재 체크아웃의 `CT-scene-rebuild/src`를 사용하고, 실행 인터프리터만 공통 엔진에서 빌리도록 분리했다. 검토·분석·화면 재렌더·수동 교정 실행 경로에 같은 해석기를 쓴다. 원본 모델 저장 폴더도 중첩 편집기 경로에서 찾도록 했다.

실제 편집기 내장 탭에서 새 소스 로드·영상 디코드·정확한 영상 저장·분석 명령의 소스와 실행 환경·중복 탭 방지·종료 보호를 확인했다. 정상 결과14검사, 실패 영상의 실패 표시를 포함한15검사 통과. 분석 명령 연결은 검사했고 전체 추론은 별도 엔진에서 수행했다. 원본4채널을 새로 검출·학습한 것이 아니라 동일 Gemini v7 관측·base·OSM 캐시를 재사용한 분석이다. 기본 UI의 실험 접점 어댑터 사용 정책 자체는 변경하지 않았다.

이미 겹침 FAIL이 기록된 결과를 열면 편집기에 “검증 실패 · 차량 겹침이 남아 있습니다”를 표시한다. 이전처럼 일반 검토 안내만 보여 실패를 놓치지 않도록 했다.
