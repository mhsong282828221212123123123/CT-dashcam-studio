# 근접 차량 가장자리 누락 보완 · 2026-11-15

사용자 지시에 따라 먼 전방 트럭의 ID 분석을 보류하고, 바로 옆 차량이 카메라 가장자리에 걸린 동안 먼저 사라지는 문제를 우선했다. 먼 차량 실험은 runs/far-identity-experiment-001에 보존하며 실제 파이프라인에 연결하지 않았다.

## 변경

검증된 두 차선 도색 기반 측방 보정이 있는 동일 차량에 한해, 영상 경계에 걸린 큰 차체의 짧은 접촉점 공백을 후보정한다. 관측된 연속 움직임이 안정적인 경우 최대 2초까지 기존 관측 시각의 위치를 보완하며 새 ID나 검출을 만들지 않는다. 작은 원거리 검출, 큰 횡이동, 긴 공백, 미보정 카메라는 제외한다. 미래 관측을 사용한 구간은 결과에 표시한다.

## 검증과 한계

- 단위 검사 343개 PASS.
- 원본 대조 4개 구간의 54프레임: 이전에는 누락, 수정 후 표시 유지. 전후 합성 화면을 육안 확인했다.
- 전체 59.67초 1194프레임 및 발췌 11초 220프레임 디코딩 완료. 배포 코드와 보존 엔진 해시 일치, 결과 artifact 무결성 PASS.
- 기존 말미 214프레임 차체 전체 차로 유지 및 선택 6개 차로/존재 검사 PASS.
