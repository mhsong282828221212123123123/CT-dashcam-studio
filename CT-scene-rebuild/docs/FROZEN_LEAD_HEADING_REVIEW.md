# 선행차 방향 동결 순서와 투영 실패 공백

`current-eight-source-witnesses-010`은 Oct26 4개, Aug16 84개 기준 관측의 방향이 base 발행 후 합성 단계에서 π만큼 변경된 것을 검출했다. 위치는 동일했다. 이 실패 기록은 보존한다.

방향의 축 연속성은 이제 `full_timeline`의 base 발행 전에 결정한다. 합성기는 동결된 선행차 방향을 수정하지 않는다. 위치 보완 구간의 속도 방향에는 앞뒤 모호성이 있으므로, 보완 행만 동결된 이웃의 방향에서 시간 순서로 이어 준다. 각 행을 하나의 고정 방향에 비교하면 실제 완만한 회전도 90도에서 뒤집히므로 그렇게 처리하지 않는다.

첫 수정본의 전체 디코드 검사는 Oct26 10.85–11초의 보완→기준 관측 전환에서 급회전을 발견했다. 두 번째 검사에서는 7초 부근의 고정 기준에 대한 90도 임계값 전환을 발견했다. 두 실패 산출물도 보존한다.

Oct26의 실제 원인은 4–11초 사이 동일한 source track이 계속 검출됐지만 지면 투영만 실패한 것이다. 이 구간을 실제 재등장으로 오인해 base의 방향 축을 새로 선택했다. 현재는 source 관측 간격이 1초 이내로 이어지는 동일 local identity에 한해, 최대 8초의 투영 실패 공백에서도 앞뒤 축 연속성을 추정한다. 실제 가시 공백과 8초를 넘는 공백은 연결하지 않는다. 이 규칙은 body 앞뒤의 추정이며 실측 방향이나 3D 위치 검증을 대신하지 않는다. 지면 투영이 안 된 동안 독립 차량이 크게 회전한 경우는 여전히 제한이다.

추가로 Oct22의 26초에서는 낮은 신뢰도의 크기 기반 위치가 정차 중 고리를 만들며 속도 방향이 회전했다. 양쪽에 동결된 body 관측이 있는 보완 구간의 방향은 이제 그 관측 사이를 보간한다. 위치 prior의 속도로 body 방향을 덮어쓰지 않는다. 동결 관측 바깥의 앞뒤 축 연결은 동결 이웃에서 시간 순서로 이어 간다.

회귀 검사는 점진적 U턴 보존, 실제 긴 가시 공백 보존, 투영만 실패한 연속 관측의 축 유지, 보완 행이 동결 행을 변경하지 않음, 두 끝의 body 방향이 크기 prior의 고리보다 우선함을 포함한다. 코드 검사 282개 통과. 최종 전체 영상은 `branch-orientation-suite-014`와 `new-date-suite-013`이다. 8개 모두 전 구간 수치 검사 통과. `current-eight-source-witnesses-015`의 기준 관측 계약과 선택 source 사건 16개도 통과했다. 소수 수치 검사의 통과를 전체 원본 일치로 표현하지 않는다.

`approach-band-source-review-full-014`의 source 도로/포켓 검사는 통과했으나, 모든 행을 예전 006/005 버전의 방향까지 포함해 동일성 비교하는 두 검사는 실패했다. 이 보고서는 보존한다. 새 base에 대한 실제 동결 계약은 위 015 검사로 별도 확인했다. 예전 보완 방향을 그대로 유지한 것으로 보고하지 않는다.
